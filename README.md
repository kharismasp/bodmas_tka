# Kirani — Story → Math
## Operations & Multistep Problem Lab · Teacher Version

### Run the lesson
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. `← Back` = previous activity/page state.
4. `PASS →` = teacher bypass for the current activity.
5. Passed activities do **not** represent mastery.
6. The site runs offline; no server, npm install, CDN, external font, API, or internet connection is required.

### Lesson order
Warming Up → Back to Zoom → Lesson with Miss → Latihan Mandiri → Final Independent Check → Finish.

### Local progress
When browser storage is available, the site preserves current activity, completed/mastered activities, skipped status, hints, and parallel-retry state in `localStorage`.
